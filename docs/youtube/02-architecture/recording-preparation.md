## 🎯 Ключевые моменты для акцента

### Проблемы которые решает DDD
1. **Сложность** — разделение на слои
2. **Тестируемость** — изоляция компонентов
3. **Масштабируемость** — слабая связанность
4. **Поддерживаемость** — четкие границы

### Преимущества EventBus
1. **Гибкость** — легко добавлять обработчики
2. **Надежность** — изоляция ошибок
3. **Производительность** — асинхронная обработка
4. **Тестируемость** — mock EventBus

### Технологические решения
1. **React** — зрелость экосистемы
2. **Node.js** — единый язык
3. **PostgreSQL** — полнотекстовый поиск
4. **Redis** — производительность кэша
