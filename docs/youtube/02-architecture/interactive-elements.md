### Вызов 1: Архитектурная викторина
**Время:** После объяснения DDD слоев (12 минута)

**Вопрос на экране:**
```
🤔 Вопрос зрителям:

В каком слое должна быть валидация email?

A) Domain Layer
B) Application Layer  
C) Infrastructure Layer
D) API Layer

Пишите ответ в комментариях! 👇
```

**Правильный ответ:** D) API Layer
**Объяснение:** Валидация формата — это HTTP-специфика, Domain знает только бизнес-правила.

### Вызов 2: Найди проблему в коде
**Время:** После показа антипаттерна (6 минута)

**Код на экране:**
```typescript
// 🔍 Найдите 5 проблем в этом коде:
class NewsService {
  async collectNews() {
    const articles = await fetch('https://rss.com/feed');
    await db.query('INSERT INTO articles...');
    await redis.del('cache:*');
    io.emit('news_updated');
    console.log('Done!');
  }
}
```

**Проблемы:**
1. Смешаны разные уровни ответственности
2. Нет обработки ошибок
3. Прямая работа с БД в сервисе
4. Жесткая связанность с WebSocket
5. Отсутствие логирования
