## 🎨 Визуальная концепция

### Цветовая схема
```css
/* Слои архитектуры */
--api-layer: #3b82f6;         /* Синий */
--application-layer: #10b981;  /* Зеленый */
--infrastructure-layer: #f59e0b; /* Оранжевый */
--domain-layer: #8b5cf6;      /* Фиолетовый */

/* Акценты */
--success: #22c55e;           /* Решения */
--error: #ef4444;             /* Проблемы */
--warning: #f59e0b;           /* Внимание */
```

### Стиль диаграмм
- **Минимализм** — чистые линии, много белого пространства
- **Контраст** — четкое разделение элементов
- **Анимации** — плавные переходы и появления
- **Типографика** — Inter для текста, JetBrains Mono для кода
