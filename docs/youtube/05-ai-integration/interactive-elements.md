## 🎯 Вызовы

### Вызов 1: Circuit Breaker состояние
**Время:** После объяснения трёх состояний (12 минута)

```
🤔 Вопрос:

NER-сервис упал. Circuit Breaker в состоянии OPEN.
Прошло 2 минуты. Следующий запрос:

A) Немедленно возвращает fallback (OPEN)
B) Пробует запрос (HALF_OPEN)
C) Ждёт ещё 2 минуты
D) Выбрасывает исключение

Пишите ответ в комментариях! 👇
```

**Правильный ответ:** B — переходит в HALF_OPEN и делает пробный запрос

### Вызов 2: Алгоритм кластеризации
**Время:** После объяснения MIN_COMMON_WORDS (20 минута)

```
🔍 Будут ли эти статьи в одном кластере?

1. "Путин провёл встречу с Байденом"
   tokens: {путин, провести, встреча, байден}

2. "Байден и Путин обсудили ситуацию"
   tokens: {байден, путин, обсудить, ситуация}

MIN_COMMON_WORDS = 2

Посчитайте общие токены и ответьте!
```

**Ответ:** Да — общие токены {путин, байден} = 2 >= MIN_COMMON_WORDS
