## 🎯 Интерактивные вызовы

### Вызов 1: Найди проблему в коде
**Время:** После объяснения последовательной обработки (8 минута)

```typescript
// 🔍 Что не так с этим кодом?
const results = await Promise.allSettled(
  sources.map(source => collectFromSource(source))
);
```

**Ответ:** Все источники опрашиваются одновременно — перегрузка серверов, burst-запросы, сложно контролировать нагрузку. Реальное решение — for...of с задержкой 500ms.

### Вызов 3: Rate limiting задача
**Время:** После объяснения RssRateLimiter (22 минута)

```
💭 Практическая задача:

У вас источник с лимитом 20 req/min.
За последнюю минуту было 18 запросов.
Burst limit: 3 запроса за 10 секунд.
За последние 10 секунд: 3 запроса.

Пройдёт ли следующий запрос?

Объясните почему в комментариях!
```

**Ответ:** Нет — burst limit исчерпан (3/3), даже если минутный лимит ещё не достигнут.
