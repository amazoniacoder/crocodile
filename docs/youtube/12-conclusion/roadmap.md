**Приоритет:** Низкий — нужен при 10+ нодах  
**Зависимость:** Требует DevOps-экспертизы

Docker Swarm (текущий подход) достаточен до ~10 нод. При росте:

- HPA (Horizontal Pod Autoscaler) по CPU/RPS
- Istio для service mesh и mTLS между сервисами
- ArgoCD для GitOps-деплоя

**Приоритет:** Низкий — UX улучшение

## Что НЕ делать

**Алгоритмическое ранжирование на сервере.** Это противоречит философии проекта — «без алгоритмов подтасовки». Пользователь видит новости в хронологическом порядке, источник всегда виден.

**Авторизация через OAuth/социальные сети.** Текущая модель (токены без регистрации) намеренно анонимна. Добавление OAuth создаёт профили пользователей — это другой продукт.

**Реклама и монетизация через данные.** Аналитика анонимна (без cookie, без IP) — это принципиальная позиция, не техническое ограничение.
