## Финальные домашние задания

### Задание 1 — для всех уровней
Форкнуть репозиторий и запустить локально. Добавить один новый RSS-источник через API:
```bash
curl -X POST http://localhost:5000/api/admin/sources \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "Ваш источник", "url": "https://...", "category": "tech", "region": "world"}'
```

### Задание 2 — Middle
Реализовать `SCAN` вместо `KEYS` в `DistributedScheduler.ts`. Написать тест, который проверяет что lock захватывается только одним из двух экземпляров.

### Задание 3 — Senior
Добавить OpenAPI-аннотации к трём эндпоинтам через `zod-to-openapi` и поднять Swagger UI на `/api/docs`.
