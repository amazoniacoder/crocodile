### Вызов 1: Найди проблему
**Время:** После объяснения виртуализации (12 минута)

```tsx
// 🔍 Что не так с этим кодом?
function NewsFeed({ articles }) {
  return (
    <div>
      {articles.map(article => (
        <NewsCard key={article.id} article={article} />
      ))}
    </div>
  );
}
// articles.length = 500
```

**Ответ:** Все 500 карточек рендерятся в DOM одновременно. Решение — useVirtualizer.
