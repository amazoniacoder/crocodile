## 🎬 Сценарий 1: Главная страница и фильтрация

### Подготовка
- Открыть `http://localhost:3000` в Chrome
- Убедиться что лента загружена (минимум 20 статей)
- Подготовить закладки для быстрого переключения

### Демонстрация (3 минуты)

#### **Шаг 1: Первое впечатление (30 сек)**
```
1. Показать главную страницу
2. Обратить внимание на:
   - Чистый дизайн карточек
   - Разнообразие источников
   - Время публикации
   - Категории статей
```

**Текст:** 
> "Сразу видно — это профессиональный новостной агрегатор. Статьи из разных источников: российских и зарубежных. Каждая карточка показывает источник, время и категорию."

#### **Шаг 2: Фильтрация по региону (45 сек)**
```
1. Кликнуть "Мир" в фильтре регионов
2. Показать как меняется лента (The Guardian, Al Jazeera)
3. Вернуться на "Россия" 
4. Показать российские источники (Lenta.ru, RBC, ТАСС)
```

**Текст:**
> "Фильтрация работает мгновенно. Россия — это Lenta.ru, RBC, ТАСС. Мир — The Guardian, Al Jazeera, Reuters. Никакого смешивания — четкое разделение по регионам."

#### **Шаг 3: Категории (45 сек)**
```
1. Выбрать "Технологии" 
2. Показать технологические новости
3. Добавить "Экономика" (множественный выбор)
4. Показать URL изменение
```

**Текст:**
> "Можно выбирать несколько категорий одновременно. Обратите внимание — URL синхронизируется с фильтрами. Этой ссылкой можно поделиться, и человек увидит именно эту выборку."

#### **Шаг 4: Поиск (50 сек)**
```
1. Ввести "искусственный интеллект" в поиск
2. Показать результаты с подсветкой
3. Попробовать английский запрос "artificial intelligence"
4. Показать морфологический поиск "ИИ"
```

**Текст:**
> "Полнотекстовый поиск работает на двух языках с морфологией. PostgreSQL GIN-индекс обеспечивает мгновенные результаты даже по базе в миллионы статей."

## 🎬 Сценарий 2: Кластеризация и похожие новости

### Подготовка
- Найти статью с меткой "Похожие новости" (или создать кластер заранее)
- Подготовить 2-3 статьи на одну тему из разных источников

### Демонстрация (1.5 минуты)

#### **Шаг 1: Найти кластер (20 сек)**
```
1. Прокрутить ленту до статьи с "Похожие новости"
2. Кликнуть на карточку
3. Показать модальное окно с похожими статьями
```

**Текст:**
> "Вот уникальная фишка — система автоматически находит похожие новости из разных источников. Это не просто поиск по ключевым словам."

#### **Шаг 2: Объяснить алгоритм (40 сек)**
```
1. Показать статьи из разных источников на одну тему
2. Обратить внимание на разные заголовки
3. Показать что система поняла суть, а не просто слова
```

**Текст:**
> "Смотрите — заголовки разные, но суть одна. Система использует NER (Named Entity Recognition) для извлечения сущностей: персон, организаций, мест. Затем алгоритм кластеризации группирует статьи по смыслу, а не по словам."

#### **Шаг 3: Entity-Driven подход (30 сек)**
```
1. Показать выделенные сущности (если есть в UI)
2. Объяснить преимущества перед обычной кластеризацией
```

**Текст:**
> "Это называется Entity-Driven Cluster. Вместо простого сравнения текстов мы анализируем упоминания людей, компаний, событий. Гораздо точнее обычных алгоритмов."

## 🎬 Сценарий 3: PWA и офлайн-режим

### Подготовка
- Убедиться что Service Worker зарегистрирован
- Подготовить DevTools для отключения сети
- Проверить что в IndexedDB есть данные

### Демонстрация (1.5 минуты)

#### **Шаг 1: Установка PWA (30 сек)**
```
1. Показать иконку "Установить" в адресной строке
2. Кликнуть установить
3. Показать приложение в отдельном окне
```

**Текст:**
> "Это полноценное PWA приложение. Можно установить как обычную программу и пользоваться без браузера."

#### **Шаг 2: Офлайн-режим (45 сек)**
```
1. Открыть DevTools → Network
2. Поставить галочку "Offline"
3. Обновить страницу
4. Показать что лента работает
5. Показать индикатор офлайн-режима
```

**Текст:**
> "А теперь магия — отключаем интернет. Приложение продолжает работать! Все статьи сохраняются в IndexedDB браузера. Пользователь может читать новости в метро без интернета."

#### **Шаг 3: Синхронизация (35 сек)**
```
1. Включить сеть обратно
2. Показать индикатор подключения
3. Показать появление новых статей
```

**Текст:**
> "Включаем сеть — и приложение автоматически синхронизируется. Новые статьи подгружаются, офлайн-действия отправляются на сервер."

## 🎬 Сценарий 4: Собственная CAPTCHA

### Подготовка
- Найти форму с CAPTCHA (или создать тестовую страницу)
- Убедиться что пазлы генерируются корректно

### Демонстрация (1 минуте)

#### **Шаг 1: Открыть CAPTCHA (20 сек)**
```
1. Найти кнопку с иконкой пазла
2. Кликнуть для открытия модального окна
3. Показать сгенерированный пазл
```

**Текст:**
> "Вместо надоевшей reCAPTCHA мы сделали собственную систему. Drag & drop пазл — интуитивно понятно и приятно использовать."

#### **Шаг 2: Решить пазл (25 сек)**
```
1. Показать 3 варианта фигур
2. Перетащить правильную фигуру в пропуск
3. Показать валидацию и успех
```

**Текст:**
> "Нужно перетащить правильную фигуру в пропуск. Система проверяет не только правильность фигуры, но и точность позиционирования. 95-98% защита от ботов."

#### **Шаг 3: Преимущества (15 сек)**
```
1. Показать закрытие модального окна
2. Показать галочку успеха
```

**Текст:**
> "Никаких внешних зависимостей, полный контроль над алгоритмом, отличный UX. Боты не знают наших паттернов — уникальное конкурентное преимущество."

## 🎬 Сценарий 6: Админ-панель мониторинга

### Подготовка
- Убедиться что ADMIN_TOKEN настроен
- Проверить что все метрики собираются
- Подготовить данные для демонстрации

### Zone A — Parser Health (1 минута)
```
1. Ввести токен для входа
2. Показать карточки обзора
3. Кликнуть на "Новые статьи за 1ч" → модальное окно
4. Показать график активности по часам
5. Показать таблицу источников с latency
```

**Текст:**
> "Зона мониторинга парсера. Видим сколько статей собрали за час, какие источники работают, какие с ошибками. Latency показывает задержку от публикации до сбора."

### Zone B — Infrastructure (1 минута)
```
1. Переключиться на вкладку "Система"
2. Показать системные метрики
3. Показать график времени циклов
4. Обратить внимание на живые обновления
```

**Текст:**
> "Системные метрики в реальном времени. RSS память, CPU load, uptime. График показывает время каждого цикла сбора — если источник завис, сразу видно."

### Zone B — Infrastructure + алерты (1 минута)
```
1. Переключиться на вкладку "Система"
2. Показать системные метрики
3. Показать график времени циклов
4. Обратить внимание на живые обновления
5. Показать историю алертов (SSL, disk, Fail2Ban — через AlertManager)
```

**Текст:**
> "Системные метрики в реальном времени. RSS память, CPU load, uptime. AlertManager проверяет 17 правил каждые 30 секунд — SSL, диск, Fail2Ban, кластер. Если что-то выходит за порог — алерт приходит сюда же через WebSocket."
