## 📋 Технические требования

### Размеры и форматы
- **Разрешение:** 1920x1080 (16:9)
- **Формат:** PNG для статичных, MP4 для анимированных
- **DPI:** 150+ для четкости текста
- **Шрифты:** Встроенные в файлы

### Экспорт
- **Figma/Sketch** для дизайна

- **PowerPoint/Keynote** для простых слайдов
- **Lottie** для веб-анимаций
