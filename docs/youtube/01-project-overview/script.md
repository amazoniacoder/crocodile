**[Переход к экрану браузера]**

**Демонстрация:**
1. **Открыть главную страницу** `http://localhost:3000`
   - Показать ленту новостей
   - Обратить внимание на дизайн карточек
   - Показать источники (Lenta.ru, RBC, The Guardian)

2. **Фильтрация**
   - Переключить регион: Россия → Мир
   - Выбрать категории: Технологии + Экономика
   - Показать как URL синхронизируется с фильтрами

3. **Поиск**
   - Ввести запрос "искусственный интеллект"
   - Показать результаты с подсветкой
   - Объяснить полнотекстовый поиск PostgreSQL

**Ключевые моменты:**
- "Обратите внимание — фильтры синхронизируются с URL. Этой ссылкой можно поделиться"

#### **Блок 2: Уникальные возможности (4 минуты)**

**1. Кластеризация новостей (1.5 мин)**

**3. Собственная CAPTCHA (1 мин)**

#### **Блок 3: Дополнительные страницы (2 минуты)**

**1. YouTube каналы** `/youtube`
- Показать встроенный плеер

**2. Telegram каналы** `/social`
- Показать виджеты постов

**3. Погода** `/weather`
- Показать прогноз на 7 дней

#### **Блок 4: Мониторинг (3 минуты)**

**[Открыть админ-панель]** `http://localhost:3000/admin/monitor`

**Ввести ADMIN_TOKEN**

**Показать Zone A — Parser Health:**
- Статистика сбора по источникам
- График активности по часам
- Таблица с latency и статусами

**Показать Zone B — Infrastructure:**
- Системные метрики (RSS, CPU, Uptime)
- График времени циклов сбора
- Живые обновления каждые 5 секунд

**Показать Zone B — Infrastructure (включая алерты безопасности):**
- Системные метрики (RSS, CPU, Uptime)
- История алертов (SSL, disk, Fail2Ban — через AlertManager)
- График времени циклов сбора

**Ключевые моменты:**
- "15 зон (A–O) покрывают все аспекты системы"
- "17 правил алертов работают независимо, проверяя условия каждые 30 секунд"
- "Все метрики в реальном времени через WebSocket"

## 🎥 Технические требования

### Подготовка к записи
- [ ] Запустить все сервисы (app, postgres, redis, ner-service)
- [ ] Наполнить БД тестовыми данными
- [ ] Подготовить несколько статей для демо кластеризации
- [ ] Настроить ADMIN_TOKEN для доступа к мониторингу
- [ ] Проверить работу офлайн-режима

### Настройки записи
- **Разрешение:** 1920x1080 (4K для финальной версии)
- **FPS:** 60 (для плавности интерфейса)
- **Битрейт:** 8000 kbps
- **Аудио:** 48kHz, стерео

### Визуальные элементы
- Диаграмма архитектуры (высокое разрешение)
- Схема потока данных
- Слайд с планом серии
- Заставка и концовка

## 📊 Ключевые метрики для демо

### Показать в мониторинге
- **RSS память:** ~150-200 MB
- **Статьи за час:** 50-100
- **Источники:** 15+ активных
- **Latency:** <30 секунд
- **SSL:** >30 дней до истечения
- **Disk usage:** <50%

### Подготовить данные
- Минимум 500 статей в БД
- 5-10 кластеров похожих новостей
- Активность за последние 24 часа
- Несколько YouTube и Telegram каналов
