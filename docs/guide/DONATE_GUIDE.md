# Система донатов — Руководство разработчика

> Актуально для версии 1.3.0+

---

## Обзор

Модальное окно «Поддержать проект» открывается кнопкой «Донат» на странице `/about`.  
Список методов оплаты управляется из кабинета мониторинга — без деплоя и правки кода.

**Поток данных:**
```
Кабинет → PATCH /api/admin/config (donate_methods_json)
        → source_config (БД)
        → GET /api/news/donate-config (cache: no-store)
        → Модалка /about
```

---

## Типы карточек

Поведение карточки в модалке определяется автоматически по полям:

| Условие | Поведение |
|---------|-----------|
| `href` пустой | Реквизит: кнопка копирования + кнопка QR-кода |
| `title` содержит «юmoney» или «yoomoney» (любой регистр) | Встроенный виджет ЮMoney с выбором суммы |
| `href` заполнен | Ссылка «Перейти к оплате» (для ЮMoney/Boosty/Patreon) |

---

## Управление в кабинете мониторинга

Маршрут: `/admin/monitor` → Зона C (🎛️ Управление) → блок «Донат: способы оплаты»

### Поля карточки

| Поле | Описание |
|------|----------|
| **Название** | Отображается заголовком карточки. Для ЮMoney виджета — должно содержать «ЮMoney» или «YooMoney» |
| **Реквизит** | Номер телефона для СБП, адрес крипто-кошелька, номер кошелька ЮMoney (`4100XXXXXXXXXX`). Отображается моноширинным шрифтом с кнопкой копирования |
| **Ссылка** | Заполнять только для ЮMoney/Boosty/Patreon. Для СБП и крипто — оставить пустым |
| **Подсказка** | Короткий hint под реквизитом (опционально) |

### Порядок карточек

Кнопки ↑ / ↓ меняют порядок отображения в модалке.  
Кнопка «+ Добавить метод» добавляет пустую карточку в конец списка.

### Сохранение

Кнопка «Сохранить» активна только при наличии несохранённых изменений.  
После сохранения серверный кэш инвалидируется немедленно — следующее открытие `/about` получит актуальные данные.

## Подключение реальных реквизитов

### СБП

1. В поле **Название** — `СБП (Россия)`
2. В поле **Реквизит** — номер телефона в формате `+7XXXXXXXXXX`
3. Поле **Ссылка** — оставить пустым
4. Пользователь увидит номер с кнопкой копирования и QR-кодом для сканирования

### USDT / BTC / ETH

1. В поле **Название** — `USDT (TRC20)` / `BTC` / `ETH`
2. В поле **Реквизит** — адрес кошелька (полный, без пробелов)
3. Поле **Ссылка** — оставить пустым
4. Адрес длиннее 20 символов без пробелов автоматически получает кнопку QR

### ЮMoney (встроенный виджет)

1. В поле **Название** — `ЮMoney` (обязательно содержит это слово)
2. В поле **Реквизит** — номер кошелька ЮMoney: `4100XXXXXXXXXX`
3. Поле **Ссылка** — оставить пустым
4. В модалке появится виджет с пресетами 100 / 300 / 500 / 1000 ₽ и полем произвольной суммы
5. Кнопка «Перейти к оплате» открывает `yoomoney.ru/quickpay` с предзаполненной суммой

> Виджет использует публичный QuickPay API ЮMoney — регистрация приложения не требуется, только номер кошелька.

### ЮMoney (внешняя ссылка, альтернатива)

Если нужна прямая ссылка без виджета:

1. В поле **Название** — любое (не содержащее «юmoney»/«yoomoney»)
2. В поле **Ссылка** — `https://yoomoney.ru/to/4100XXXXXXXXXX`
3. Пользователь увидит кнопку «Перейти к оплате»

### Boosty / Patreon

1. В поле **Название** — `Boosty` / `Patreon`
2. В поле **Реквизит** — название страницы или короткое описание
3. В поле **Ссылка** — полный URL страницы (`https://boosty.to/...`)
4. Пользователь увидит кнопку «Перейти к оплате»

## Архитектура

### Серверная часть

| Файл | Роль |
|------|------|
| `server/domain/monitoring/SourceConfig.ts` | Тип `SourceConfigKey`, дефолтное значение `donate_methods_json` |
| `server/infrastructure/persistence/SourceConfigRepository.ts` | Чтение/запись в таблицу `source_config` |
| `server/api/admin/config.ts` | `PATCH /api/admin/config` — валидация и сохранение |
| `server/api/news/index.ts` | `GET /api/news/donate-config` — публичный эндпоинт, Redis-кэш с ключом `news:donate-config` |

**Инвалидация кэша** при сохранении:
```typescript
await invalidateCache('news:donate-config'); // точный ключ, не glob
```

### Клиентская часть

| Файл | Роль |
|------|------|
| `client/src/pages/about.tsx` | Модалка, компоненты `DonateCard` и `YooMoneyWidget` |
| `client/src/components/admin/monitor/ZoneC/DonateConfig.tsx` | Форма редактирования в кабинете |
| `client/src/ui-system/patterns/donate.css` | Все стили модалки и виджета |

**Fetch без кэша:**
```typescript
fetch('/api/news/donate-config', { cache: 'no-store' })
```
Браузер всегда делает запрос к серверу — изменения из кабинета видны сразу при следующем открытии страницы.

### Схема БД

Методы хранятся в таблице `source_config` как JSON-строка:

```sql
SELECT value FROM source_config WHERE key = 'donate_methods_json';
```

Формат значения:
```json
[
  { "title": "СБП (Россия)", "value": "+79001234567", "note": "Самый быстрый способ", "href": "" },
  { "title": "ЮMoney",       "value": "4100123456789", "note": "",                      "href": "" },
  { "title": "Boosty",       "value": "Поддержать на Boosty", "note": "",              "href": "https://boosty.to/..." }
]
```

## Добавление нового типа виджета

Пример: добавить Telegram Stars или другой провайдер.

1. Добавить регулярное выражение-детектор в `about.tsx` по аналогии с `YOOMONEY_RE`
2. Создать компонент виджета (аналог `YooMoneyWidget`)
3. Добавить ветку в `DonateCard`:
```typescript
if (/telegram|stars/i.test(item.title)) {
  return <TelegramWidget wallet={item.value} note={item.note} />;
}
```
4. Добавить стили в `ui-system/patterns/donate.css`

---

## Валидация на сервере

`server/api/admin/config.ts` → `sanitizeDonateMethods()`:

- `title` и `value` обязательны — карточки без них отфильтровываются
- `href` если заполнен — должен быть валидным URL с протоколом `https` / `http` / `tg` / `mailto`
- Пустой массив после фильтрации — ошибка 400

---

## Дефолтные методы

Если в БД нет записи `donate_methods_json` — сервер возвращает дефолт из `SOURCE_CONFIG_DEFAULTS` (`server/domain/monitoring/SourceConfig.ts`).  
Клиент (`about.tsx`) имеет собственный fallback `SUPPORT_CHANNELS` — используется только если запрос к API упал с ошибкой.
