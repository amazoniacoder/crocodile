# Монетизация Telegram-лент — План реализации

> Статус: Планирование  
> Версия: 1.0  
> Дата: Май 2025

---

## Концепция

Пользователи в РФ не имеют стабильного доступа к Telegram из-за блокировок и нестабильности VPN.
Crocodile предоставляет агрегированный контент Telegram-каналов прямо в браузере — без VPN, без установки приложений.

Монетизация строится на модели **freemium**: базовый доступ бесплатный, расширенный — по токену подписки.

---

## Модель доступа

### Бесплатно (без токена)

- Один канал — **витринный**, выбирается командой проекта
- Показывает полную функциональность: посты, картинки, видео, виджет Telegram
- Цель: демонстрация ценности продукта новым пользователям

### По подписке (с токеном)

- Все остальные каналы — **5 последних постов** видны без токена
- Начиная с 6-го поста — форма ввода токена с пояснением и ссылкой на Boosty
- Новые каналы добавляются **по запросу пользователей** через форму обратной связи

---

## Токен подписки

| Параметр | Значение |
|----------|----------|
| Источник | Boosty — разовый платёж или подписка |
| Цена | ~100 ₽ / месяц |
| Срок действия | 30 дней с момента активации |
| Привязка | Браузер (`localStorage`), без привязки к аккаунту |
| Устройств | Без ограничений — один токен можно использовать на нескольких браузерах |
| Регистрация | Не требуется — анонимная активация |

## Пользовательский флоу

```
Пользователь открывает страницу канала
  ↓
Видит 5 последних постов бесплатно
  ↓
При скролле к 6-му посту — появляется блок-заглушка:
  "Для просмотра полной ленты нужен токен подписки"

  ↓

  ↓

  ↓

  ↓
Полная лента канала открыта на 30 дней
```

## Техническая реализация

### Хранение токенов

Таблица `subscription_tokens` в PostgreSQL:

```sql
CREATE TABLE subscription_tokens (
  token        TEXT PRIMARY KEY,          -- SHA-256 хэш токена
  created_at   TIMESTAMPTZ DEFAULT NOW(),
  expires_at   TIMESTAMPTZ NOT NULL,      -- created_at + 30 дней
  is_active    BOOLEAN DEFAULT TRUE,
  note         TEXT                       -- опционально: метка (напр. "boosty-batch-05-2025")
);
```

Токены генерируются администратором в кабинете мониторинга (Zone C или новая Zone L2) и выдаются через Boosty.

### API

```
POST /api/token/validate
Body: { token: string }
Response: { valid: boolean, expiresAt: string | null }
```

- Токен передаётся хэшированным (SHA-256 на клиенте перед отправкой)
- Сервер сверяет хэш с таблицей, проверяет `expires_at` и `is_active`
- Результат кэшируется в Redis на 5 минут по хэшу токена

### Клиент

```typescript
// localStorage ключ
const TOKEN_KEY = 'crocodile_sub_token';
const TOKEN_EXPIRY_KEY = 'crocodile_sub_expiry';

// При вводе токена
localStorage.setItem(TOKEN_KEY, token);
localStorage.setItem(TOKEN_EXPIRY_KEY, expiresAt);

// При каждом запросе ленты канала
const token = localStorage.getItem(TOKEN_KEY);
// Передаётся в заголовке: X-Sub-Token: <token>
```

### Серверная проверка

Middleware `requireSubscription` применяется к эндпоинту ленты канала:

```
GET /api/telegram/channel/:username/posts?page=2+
  → requireSubscription middleware
  → проверяет X-Sub-Token
  → если невалидный или отсутствует → 402 Payment Required
  → если валидный → отдаёт посты
```

Первая страница (5 постов) отдаётся без проверки токена.

## Витринный канал

- Выбирается вручную в кабинете мониторинга (флаг `is_featured` в таблице `news_sources`)
- Полностью открыт без токена
- Рекомендуется выбрать канал с высокой активностью и разнообразным контентом (текст + медиа)
- Можно менять по необходимости без деплоя

---

## Добавление новых каналов

Каналы добавляются **по запросу**:

1. Пользователь отправляет запрос через форму обратной связи (уже реализована)
2. Администратор проверяет канал и добавляет через кабинет мониторинга
3. Новый канал автоматически попадает в платный доступ (5 постов бесплатно)

Это исключает необходимость заранее наполнять каталог — аудитория сама формирует список нужных каналов.

---

## Управление токенами (кабинет мониторинга)

Новая вкладка в Zone C или отдельная зона:

- Генерация пакета токенов (напр. 10, 50, 100 штук)
- Просмотр активных токенов: количество, срок истечения
- Деактивация токена вручную
- Статистика: сколько токенов активно, сколько истекло за период

---

## Boosty — интеграция

- Создать уровень подписки "Поддержка + доступ к Telegram-лентам" (~100 ₽/мес)
- После оплаты Boosty отправляет токен в личное сообщение или показывает на странице
- Токены генерируются заранее пакетами и хранятся в БД
- Альтернатива: ручная выдача через личные сообщения на Boosty (на старте проще)

---

## Что НЕ меняется

- Основная RSS-лента — полностью бесплатна
- Поиск, погода, источники — бесплатны
- Анонимность — токен не привязан к личности
- Принцип "без рекламы" — сохраняется
